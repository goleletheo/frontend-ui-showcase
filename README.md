# Frontend UI Showcase

A clean, modern React + TypeScript frontend project demonstrating reusable UI components, responsive layouts, and solid component architecture.

Built with Vite, React 18, TypeScript, and CSS Modules.

## Features

- Reusable Button, Card, Input, and Badge components
- Dashboard layout with sidebar and header
- Responsive design
- TypeScript throughout
- Clean folder structure

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18
- TypeScript
- Vite
- CSS Modules

## Structure

```
src/
  components/     # Reusable UI components
  pages/          # Page-level components
  styles/         # Global styles
  App.tsx
  main.tsx
```
